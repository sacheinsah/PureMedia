What this version actually supports

JPEG

Re-encodes pixels into a fresh JPEG, discarding common EXIF/XMP/IPTC container metadata.

PNG

Re-encodes the image to remove ancillary text/provenance chunks that are not part of the visible pixels.

WebP

Re-encodes into a fresh file, dropping common EXIF/XMP metadata carried in the original container.

MP4 / MOV / M4V

Removes supported top-level C2PA/JUMBF UUID boxes while preserving the remaining file bytes.

Important: There is no technically honest “universal invisible-watermark remover.” Pixel/frame watermark systems such as SynthID are not ordinary metadata and can survive re-encoding. This project therefore does not claim guaranteed removal of all invisible watermarking or platform-side classifiers.
